# How to ask for something (Q203)

Copy this, fill in what you know, leave the rest blank. Claude fills the gaps with questions (or type `/feature` plus one line and
Claude fills the form for you). One line per field is enough.

```
Goal:           what you want, in one sentence ("a Drift button on phones")
Where:          which screen / mode / car / part ("Drift race screen, phone sideways")
Look & feel:    how it should look or feel; attach a drawing or screenshot if you have one
Done when:      how you'll know it's right ("I can drift with my thumb without covering the gas pedal")
Must not change: anything that has to stay as it is ("PC layout stays the same")
Size:           small fix (patch) or new feature (minor update)? — "not sure" is fine
```

## Example

```
Goal:           Phone players can play Drift.
Where:          Drift race screen, phone sideways (844x390).
Look & feel:    Same Bevel+ buttons as the drag race on phones; Drift button big enough for a thumb.
Done when:      I can finish a Drift run on my phone and the buttons never cover each other.
Must not change: PC Drift layout.
Size:           Feature.
```

## What makes an ask clear

| Do | Instead of |
|---|---|
| Name the screen ("Body Shop ▸ Paint tab") | "the menu" |
| Say what "done" looks like | "make it better" |
| One request per line, numbered | a long paragraph with several asks |
| Refer to Claude's items by their labels ("A2: yes, B3: option B") | "the second thing" |
| Say "ship it" only when you want it live | "looks good" (Claude can't tell if that means ship) |
